# Support

ChatAI is maintained by [NightZeros](https://nightzeros.com) and the community. Support is best-effort.

## Where to ask

| You want to…                                           | Go to                                                                                           |
| ------------------------------------------------------ | ----------------------------------------------------------------------------------------------- |
| Learn how something works                              | [Documentation](https://docs.nightzeros.com/docs)                                               |
| Ask a question or share an idea                        | [GitHub Discussions](https://github.com/nightzeros/chatai/discussions)                          |
| Report a bug                                           | [Bug report](https://github.com/nightzeros/chatai/issues/new?template=bug_report.yml)           |
| Request a feature                                      | [Feature request](https://github.com/nightzeros/chatai/issues/new?template=feature_request.yml) |
| Report a security vulnerability                        | Privately, as described in [SECURITY.md](./SECURITY.md). Never in a public issue                |
| Hosted service (app.nightzeros.com) account or billing | hello@nightzeros.com                                                                            |

## Before opening an issue

- Check the [troubleshooting notes](https://docs.nightzeros.com/docs/voice#troubleshooting) for Voice and the [environment reference](https://docs.nightzeros.com/docs/self-hosting/env-reference) for configuration.
- Search existing [issues](https://github.com/nightzeros/chatai/issues) and Discussions.
- Include your ChatAI version (the `VERSION` file, the Docker image tag, or the npm package version), how you run it, and steps to reproduce.
- Remove secrets, API keys, `.env` contents and visitor data from logs and screenshots.

## Versions

Only the latest minor release gets regular fixes. See the support table in [SECURITY.md](./SECURITY.md#supported-versions).
