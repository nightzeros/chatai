ChatAI is an open-source platform to **create an AI assistant, feed it your knowledge, test it, and embed it** on a website. Built by [NightZeros](https://nightzeros.com) (NZ/001).

## What you will build

1. An assistant with instructions and a welcome message
2. A knowledge base (uploads, FAQs, or a crawled website)
3. Answers in the playground with citations and a debug trace
4. An embeddable widget or React component on your site
5. Optional API access with hashed keys and the TypeScript SDK
6. Optional spoken conversations in the widget with [Voice (preview)](/docs/voice)

Version 1.1 is a **public preview**: the `/api/v1` contract and widget embed are stable, while Voice is still in preview. See the [changelog](https://github.com/nightzeros/chatai/blob/main/CHANGELOG.md).
